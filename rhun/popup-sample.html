rhun hover card with a new code_bg key

One new theme key colors the hover card and every Markdown code block. A theme can set it; when it doesn't, rhun derives it from the editor background toward the text color: darker on light themes, lighter on dark ones.

code_bg = #505152        # optional
# default when missing:
#   light theme: editor bg mixed 6% toward the text color
#   dark theme:  editor bg mixed 16% toward the text color

What the PR would change in rhun
  1. New theme key code_bg (src/app/theme.s): hover card and Markdown code-block background. Optional; default is the editor bg mixed toward the text color, 6% on light themes (darker) and 16% on dark themes (lighter).
  2. Hover card (src/app/hovercard.s): filled with code_bg; lines between sections drawn in border mixed 25% toward the text color.
  3. Plain code words (src/app/markdown.s): words the highlighter leaves uncolored use the theme's text color, as in the editor, instead of the interface fg.
  4. Hover card text: the description uses the editor font and the editor text color, so the whole card reads like code docs in the editor.
  5. Copy button: a new outline copy icon (ic_copy) replaces the "Copy" label, "Copy" as its tooltip.
